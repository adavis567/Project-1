Testing and Debugging

The group tested the program for:

- Displaying resources from the input file.
- Creating valid reservations.
- Preventing duplicate reservation IDs.
- Detecting invalid resource IDs.
- Changing resources from available to unavailable after reservation.
- Adding students to the waiting list when a resource is unavailable.
- Cancelling active reservations.
- Returning resources to available status after cancellation.
- Automatically assigning an available resource to the next student
  in the waiting list.
- Displaying active reservations.
- Displaying the waiting list.
- Displaying cancellation history.
- Undoing the most recent cancellation.
- Handling invalid menu choices.
- Handling invalid numeric input.
- Handling an unavailable resources input file.


GitHub Contributions

The group uses GitHub for version control and collaboration.

Each member works on their assigned project components and contributes
changes through GitHub branches and commits.

The group will merge feature branches into the main branch and test the
integrated project before submission.
